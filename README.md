# Coral Club · Реестр инициатив

Прототип веб-приложения для сбора и классификации инициатив руководителей функций
(привязка к проектам компании или к целям стратегических треков), плюс админ-панель
для управления справочниками (проекты, треки/цели/KR, отделы) и просмотра поданных
инициатив.

Всё приложение — один файл `index.html` (HTML + CSS + JS, без сборки, без зависимостей
кроме шрифта Inter с Google Fonts).

## Как открыть локально

Просто откройте `index.html` в браузере — двойным кликом или через
`File → Open`. Ничего устанавливать не нужно.

## Пароли доступа

- `ILoveCoralClub` — режим руководителя функции (заполнение формы инициативы)
- `IamCoralEvo` — режим администратора (редактирование справочников)

⚠️ **Это не настоящая защита.** Пароли проверяются прямо в браузере (в JS-коде
страницы), поэтому любой человек, открывший исходный код страницы, может их
увидеть. Это ограничивает случайный доступ, но не защищает от того, кто
целенаправленно посмотрит код. Для реальной защиты нужна серверная авторизация.

## Хранение данных

Приложение хранит все данные (проекты, треки, отделы, поданные инициативы) в
`localStorage` браузера. Это значит:

- Данные **не общие** — у каждого пользователя (и в каждом браузере/устройстве)
  своя отдельная копия данных.
- Если администратор что-то поменяет в своём браузере (например, тип проекта),
  руководители функций в своих браузерах этого изменения не увидят.
- Данные живут, пока их не очистить (очистка кэша/localStorage браузера сотрёт
  их).

Это подходит для демонстрации и локального тестирования, но **не подходит для
реального сбора инициатив от многих людей** — для этого понадобится общее
серверное хранилище (например, база данных или Netlify Blobs) вместо
localStorage. Дайте знать, если нужно будет это добавить.

## Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub и запушите в него этот проект:
   ```bash
   git remote add origin https://github.com/<ваш-аккаунт>/<название-репо>.git
   git branch -M main
   git push -u origin main
   ```
2. В репозитории на GitHub: **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку **main**, папку **/ (root)** → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу вида
   `https://<ваш-аккаунт>.github.io/<название-репо>/`.
